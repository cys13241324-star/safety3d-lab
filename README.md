# 산업안전 규격 실습장 3D

산업안전기사 기출에 나오는 수치 규정을 3D 현장에서 슬라이더로 바꿔 보며 적합·부적합을 확인하는 실습장입니다.
6과목 34주제(낙하물 방지망, 안전난간, 굴착면 기울기, 롤러기 급정지장치, 지게차 헤드가드, 누전차단기, 밀폐공간 적정공기 등)를 담고 있습니다.

- 실행: `index.html` 하나로 동작합니다 (Three.js는 cdnjs, 글꼴은 Google Fonts에서 불러옵니다).
- 조작: 드래그 회전 · 우클릭/Shift 드래그 이동 · 휠 확대 · 방향키 이동.
- 각 주제마다 규정 기준값, 근거 법령(법률 ▸ 규칙 ▸ 조문), 시험 버튼(규정을 어기면 사고가 재현됩니다), 기출 문항 카드가 붙어 있습니다.
