# 산업안전기사 학습실

산업안전기사 필기를 여섯 갈래로 공부하는 정적 사이트입니다. 페이지마다 파일 하나로
동작하고, 빌드 도구나 서버가 필요 없습니다. `index.html` 이 대문입니다.

| 페이지 | 무엇을 하는가 | 규모 |
|---|---|---|
| `lab.html` | **3D 규격 실습장** — 높이·거리·각도로 정해진 규정을 3D 현장에 세우고 슬라이더로 값을 바꾸면 적합·부적합이 그 자리에서 판정된다 | 6과목 21주제 |
| `memo.html` | **암기 은행** — 빈출 묶음마다 사실·훅·왜·구분 네 줄로 정리한 노트. 사실을 가리고 훅만 보면 자가 시험이 된다 | 165묶음 · 암기법 613 · 빈칸 카드 485 |
| `palace.html` | **암기 순찰로** — 같은 165묶음을 3D 현장 순찰 경로 위 정거장으로 세운 기억의 궁전 | 165정거장 · 6구역 |

## 어디서 값이 오는가

**법령 수치를 지어내지 않는다.** 카드와 실습장의 기준값은 두 곳에서만 온다.

- `lab.html` 의 `T[주제].rules` — 주제마다 판정식과 기준 문장이 붙어 있다
- `sanup-safety-cbt/build/_laws.json` — 법제처 조문 원문 12개 법령

확정하지 못한 값은 `docs/reigns/laws.md` 의 「확인 실패」 목록에 남기고 카드를 만들지
않는다. 별표(교육시간 · 안전보건관리비 요율 등)는 그 파일에 없으므로 그 목록에 있다.

빈출 지도의 순위는 CBT 회차 문항에 붙은 출제빈도를 합산한 것이고, 회차·암기 묶음
링크는 **문항 번호로** 잇는다 — 이름이 바뀌어도 번호는 안 바뀐다.

## 도구

숫자는 손으로 옮겨 적지 않는다. 전부 아래 도구가 파일에서 읽어 낸 값이다.

```
python tools/deckcov.py       덱이 기출을 덮는지 — 과목 배분 · 빈출 문턱별 커버율
python tools/deckcov.py --miss 10   빈출인데 덱에 없는 주제
python tools/build_focus.py   focus.html 을 회차와 암기 은행에서 다시 짓는다
python tools/focuscheck.py    지어낸 focus.html 이 성한지 여섯 갈래로 본다
python tools/linkcheck.py     여섯 페이지가 서로 이어지는지 · 해시가 대상에 있는지
python tools/check.py         reigns 검사기 모음 (artlint · anchor · lawcheck · hitcheck · shape · onobj)
python tools/sim-balance.py   밸런스 몬테카를로 (게이지 넷만 모형으로 삼는 구버전)
cscript //nologo tools/harness.js reigns.html 300    shipped 코드를 그대로 돌리는 하네스
```

설계 문서는 `docs/reigns/` 에 있다. `measured.md` 를 먼저 읽으면 된다 — 무엇을
재고 무엇이 틀렸는지가 시간 순으로 적혀 있다.

## 실행

파일을 브라우저로 열면 된다. 바깥에서 받아 오는 것은 글꼴(Google Fonts)과
`lab.html` 의 Three.js, `focus.html` 의 KaTeX(cdnjs) 뿐이고, 자료는 전부 파일 안에 있다.
