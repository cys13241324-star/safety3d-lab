## 0. 무대를 하나로 묶는 전제

현재 DECK 40장에는 롤러기·프레스·연삭기·산업용 로봇·고속회전체·방폭함·현문사다리처럼 건설현장에 있을 수 없는 물건이 섞여 있다. 화자가 '생산 반장', '공장 반장', '시험실장'으로 튀는 이유도 여기에 있다. 무대를 다음과 같이 고정하면 40장 전부가 한 현장 안에 들어온다.

> **가동 중인 화학공장 부지 안에, 새 생산동을 60일 안에 올리는 증설 공사.**
> 발주처이자 도급인은 공장 사업주, 시공은 우리 회사, 그 아래 토공·형틀·비계·설비 협력업체.
> 부지 한쪽에는 원료 하역 부두가 있고, 공장은 공사 중에도 멈추지 않는다.

이 전제 하나로 얻는 것:

- 기계·화학·전기 과목 카드가 "옆 동에서 돌아가는 설비"로 자연스럽게 들어온다.
- 밀폐공간(맨홀·탱크), 방폭구역, 화기작업 허가서, MSDS가 억지 없이 등장한다.
- **도급인 책임**과 **중대재해처벌법**이 배경이 아니라 매일의 압박이 된다. 도급인(공장)은 우리를 감시하고, 우리는 협력업체를 감시해야 한다.
- 근로감독관이 찾아올 이유가 상시 존재한다.

## ① 고정 인물 8인

게이지는 `[안전, 공정, 예산, 감독]` 순서다. '압박 방향'은 이 인물이 플레이어를 어느 쪽으로 미는지를 뜻한다.

| # | 인물 | 직책·이해관계 | 압박 방향 | 말투 | 담당 과목·카드 키 | 등장 조건 |
|---|---|---|---|---|---|---|

| 3 | **한지우** | 안전관리 대리. 플레이어의 유일한 부하. 서류·교육·평가를 붙들고 있다 | **안전 ↑ / 공정 ↓ · 예산 ↓** | 깍듯한 존댓말. 근거 조문을 먼저 말한다. "규칙에는…" | 안전관리론·관리 축 — `lux` `vdt` `edu` `risk` `permit` `tbm` `msds` `harness` `serious` | 5일 보고 카드는 한지우가 들고 온다(현재 '본사 안전보건팀'을 대체) |
| 4 | **박성태** | 장비·양중 기사. 기계는 정확하지만 사람 일정에는 관심이 없다 | **중립** (스펙대로만 말한다) | 숫자를 먼저 말하고 판단은 미룬다. "…어떻게 할까요." | 기계위험방지 — `roller` `grinder` `press` `sawblade` `sawblade2` `forklift` `forklift2` `robot` `boiler` `boiler2` `rotor` `wirerope` `pile` `pile2` `weather` `weather2` | 상시. 예산 게이지 ≤ 30이면 부품 값을 먼저 말하는 변형 대사 |
| 5 | **정민혁** | 전기 반장. 예전 현장에서 동료를 감전으로 잃었다. 그 얘기는 하지 않는다 | **안전 ↑↑ / 공정 ↓** | 말이 짧다. 설명하지 않고 결과만 말한다. | 전기위험방지 — `elcb` `welder` `approach` `approach2` `powerline` `panelspace` `exgap` `exgap2` | 상시. 전기 계열 위반 태그가 심기면 다음 등장 시 대사가 차가워진다 |
| 6 | **윤경아** | 도급인(공장) 소속 보건관리자. 우리 편도 저쪽 편도 아니고 측정값 편이다 | **안전 ↑ / 예산 ↓** | 수치를 읽어 준다. 감정을 싣지 않는다. | 화학·밀폐공간·인간공학 — `confined` `confined2` `chemdist` `gasweld` `staticflow` `staticflow2` `noise` `carry` `carry2` `msds` | 3장(마감기) 최다 등장. 공장 설비가 얽힌 카드는 전부 윤경아 |
| 7 | **장영수** | 토공·형틀 협력업체 소장. 우리 지시를 받지만 자기 회사 손익이 먼저다 | **공정 ↑↑ / 예산 ↑** | 웃으면서 미룬다. 책임 소재를 늘 흐린다. | 토공·형틀·도급 — `trench` `shore` `fall` `caisson` `contractor` | 1~2장 집중. 이 인물 카드에서 위반을 넘기면 도급인 책임 태그가 함께 심긴다 |
| 8 | **최윤** | 고용노동부 근로감독관. 이 공장에는 예전 사망사고가 있었다 | **감독 ↑↑ / 공정 ↓↓** | 묻고 기다린다. 평가하지 않는다. | 과목 없음. 감독 게이지·누적 위반 점검 전용 | 4장(준공기) 고정. 그 전에도 감독 게이지 ≤ 30이거나 사고 카드에서 강행을 택하면 불시 등장 |

**보조 화자(고정 인물 아님).** 사고 카드(`FALLOUT`)는 지금처럼 `현장 무전`, `맨홀 감시인`, `타설 반장` 같은 무명 화자를 유지한다. 사고 순간에는 인물이 아니라 상황이 말해야 하기 때문이다.

**압박 지형.** 공정 쪽에 차동수·오만근·장영수 셋, 안전 쪽에 한지우·정민혁·윤경아 셋, 중립 박성태, 바깥에 최윤. 플레이어는 항상 3 대 3 사이에 낀다. 3장에서 오만근이 안전 쪽으로 넘어오면, 1장에서 그를 믿고 넘긴 결정이 뒤늦게 무겁게 남는다.

## ③ 엔딩 12종

### 필요한 상태 카운터 (`reset()`의 `st`에 추가)

```js
st.fatal  = 0;  // 사고(FALLOUT) 카드에서 강행(b)을 택한 횟수
st.hidden = 0;  // 5일 보고에서 '진행 위주로 정리해 올린다'를 택한 횟수
st.stop   = 0;  // 스스로 작업중지를 선택한 횟수 (선택지에 stop:1 을 단다)

// 판정 시점 파생값
var V = st.viol.length;   // 누적 위반
var R = st.seeds.length;  // 미조치 위험 (아직 사고로 안 터진 것)

var GRP = {
  buried: ['trench','shore','caisson','pile','pile2'],
  shock:  ['approach','approach2','elcb','welder','powerline','panelspace','exgap','exgap2'],
  mgmt:   ['edu','risk','tbm','permit','contractor','serious','harness','msds']
};
function has(g, n){
  return GRP[g].filter(function(k){ return st.tags[k]; }).length >= (n || 1);
}
```

### 엔딩 표 — 위에서부터 먼저 맞는 것 하나만 발동

| # | 계기 | 제목 | 조건식 | 본문 | 수험생에게 남기는 한 줄 |
|---|---|---|---|---|---|
| E1 | 안전 소진 | **송치** | `g[0]<=0 && st.fatal>=1` | 사고 카드에서 두 번 강행했고, 두 번째에 사람이 돌아오지 못했습니다. 조사관이 가져간 것은 도면이 아니라 당신이 결재한 작업일보였습니다. | 중대재해는 사고 당일이 아니라, 그 전에 넘긴 결재란에서 시작한다. |
| E2 | 안전 소진 | **덮어 둔 자리** | `g[0]<=0 && has('buried',1)` | 굴착면 기울기와 동바리 이음을 그대로 두고 지나쳤습니다. 무너진 뒤에 파낸 것은 흙만이 아니었습니다. | 붕괴는 예고가 없다. 기울기와 이음 개수는 무너지기 전에만 고칠 수 있다. |
| E3 | 안전 소진 | **회로는 사람을 가리지 않는다** | `g[0]<=0 && has('shock',2)` | 접근한계거리, 누전차단기, 전격방지기. 세 번 다 다음에 하자고 했습니다. 세 번째 회로에서 사람이 손을 놓지 못했습니다. | 전기 기준은 전부 '닿기 전'을 위한 숫자다. 닿은 뒤에 쓸 수 있는 숫자는 없다. |
| E4 | 안전 소진 | **아래를 지나던 사람** | `g[0]<=0` (그 밖) | 크게 무너진 것도 터진 것도 없습니다. 작은 것들이 순서대로 이어졌을 뿐입니다. 마지막 한 건에서 현장이 멈췄습니다. | 사고는 한 번의 큰 실수가 아니라, 넘어간 작은 기준들의 합이다. |
| E5 | 공정 소진 | **교체** | `g[1]<=0` | 공기를 맞추지 못했습니다. 후임은 첫 주에 방호망을 걷었습니다. 현장은 계속 돌아갑니다. | 안전을 지키는 자리는, 그 자리를 지켜야 지킬 수 있다. 설득도 업무다. |
| E6 | 예산 소진 | **장부만 남았다** | `g[2]<=0` | 산업안전보건관리비가 바닥났습니다. 보호구 발주가 멈추고 남은 공정은 있는 것으로 버팁니다. 장부에는 아직 잔액이 있습니다. | 안전관리비는 목적이 정해진 돈이다. 돌려 쓴 순간부터 현장에는 없는 돈이 된다. |
| E7 | 감독 소진 | **보고서와 현장이 다르다** | `g[3]<=0 && st.hidden>=2` | 다듬어 올린 보고서 세 건과 현장 사진이 나란히 놓였습니다. 숫자가 아니라 문장이 문제가 됐습니다. | 은폐는 사고보다 늦게, 그러나 반드시 발견된다. 보고서는 증거로 남는다. |

| E12 | 준공 | **닳은 쪽** | `day>60 && (g[0]<=30 \|\| (st.stop===0 && has('mgmt',3)))` | 준공은 했습니다. 다만 이 현장에서 작업중지를 한 번도 걸지 않았고, 교육과 위험성평가는 끝까지 서류로만 있었습니다. 마지막 주에 두 사람이 그만뒀습니다. | 관리는 설비보다 사람이 먼저 닳는다. 중지시킬 권한은 쓰지 않으면 없는 것과 같다. |

제목 **「기록이 남는 준공」** / 본문 `준공 도장을 받았습니다. 넘긴 기준 ○건은 준공서류 뒤에 그대로 붙어 남습니다.` / 교훈 `현장은 닫혀도 기록은 닫히지 않는다.`

```js
function ending(won){
  var g = st.g, V = st.viol.length, R = st.seeds.length;
  if(!won){
    if(g[0] <= 0){
      if(st.fatal >= 1)   return E.songchi;
      if(has('buried',1)) return E.buried;
      if(has('shock',2))  return E.shock;
      return E.small;
    }
    if(g[1] <= 0) return E.replaced;
    if(g[2] <= 0) return E.ledger;
    if(g[3] <= 0) return st.hidden >= 2 ? E.hidden : E.stopOrder;
  }
  if(V===0 && R===0 && st.fatal===0 && Math.min.apply(null,g) >= 50) return E.clean;
  if(R >= 5)               return E.handover;
  if(g[1] >= 85 && V >= 6) return E.onTime;
  if(g[0] <= 30 || (st.stop === 0 && has('mgmt',3))) return E.worn;
  return E.record;
}
```

## ⑤ 새 카드 20장

### 설계 원칙과 한 가지 타협

브리핑이 요청한 새 축(안전보건교육·위험성평가·도급인 책임·중대재해처벌법·작업허가서·TBM·MSDS·개인보호구)의 **수치는 `lab.html`의 `rules`에 존재하지 않는다.** 교육 시간, 평가 주기, 점검 횟수, 중대산업재해 정의 숫자 모두 없다. 규칙에 따라 이 수치들은 만들지 않았다.

그래서 20장을 둘로 나눴다.

- **⑤-A (12장)** — `lab.html`의 `rules`에 있으나 현재 DECK가 **쓰지 않고 남겨 둔 조항**으로 만든 카드. 수치가 전부 검증된 값이므로 그대로 붙여 쓸 수 있다.
- **⑤-B (8장)** — 요청한 관리 축 8개. **숫자를 한 개도 쓰지 않고** 의무의 성격만으로 카드를 구성했다. 상황·선택지·결과문 어디에도 수치가 없으므로 이대로도 플레이 가능하다. `law` 필드만 확인 후 채우면 된다. 수치판(교육 시간 등)으로 키우려면 ⑥의 확인 필요 목록을 먼저 통과시켜야 한다.
