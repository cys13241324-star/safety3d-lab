# 「안전관리자의 하루」 설계 문서

`reigns.html` 을 지으면서 나온 조사·규격 문서 여덟 편. 에이전트 다섯이 나눠 맡았고,
숫자는 전부 `tools/harness.js` 나 `tools/sim-balance.py` 로 실제 측정한 값이다.

| 문서 | 내용 |
|---|---|
| `measured.md` | **먼저 읽을 것.** 구조 결함·처방 비교와, 관리비·위험 확률을 넣고 다시 잰 값 |
| `systems.md` | 밸런스 재설계 — P형/B형 부호 설계, 40장 전량 `d` 배열, 점수·랭크 |
| `story.md` | 인물 8인 · 국면 4장 · 엔딩 12종 · 다시 쓴 10장 · 검증된 수치 12장 |
| `story-b.md` | 관리 축 8장 완성본과 신규 5장 (작업중지권 등) |
| `ux.md` | 진단표 · 학습 루프와 저장 스키마 · 온보딩 · 모바일 · 접근성 |
| `visual.md` | 장면 감사와 재작도 27종 · 프리미티브 33종 · 모션 · 카드 레이아웃 실측 |
| `research.md` | 깃허브 레퍼런스와 라이선스 · 채택 권고 3가지 |
| `laws.md` | 법제처 조문으로 확정한 값과, **확정 못 해 카드로 만들지 않은 것** |

## 한 가지 원칙

**법령 수치를 지어내지 않는다.** 출처는 `lab.html` 의 `rules` 배열과
`sanup-safety-cbt/build/_laws.json` 의 조문 원문 둘뿐이다. 확정 못 한 값은
`laws.md` 의 「확인 실패」 목록에 남기고 카드를 만들지 않았다. 별표(교육시간 등)는
이 두 출처에 없으므로 법제처 OPEN API 를 따로 타야 한다.
